# Alignment Check

Verify that the implementation is 100% aligned with the `implementation_plan.md`:

1. **Scope**: Do the actual file changes match the **Proposed Changes** list?
2. **Logic**: Does the implementation follow the planned design and resolve all **Open Questions**?
3. **Tests**: Has the **Verification Plan** been fully executed and passed?
4. **Alignment Resolution**: If the implementation is not aligned, do not rewrite or modify the code directly. Report the alignment gaps and update the implementation plan or seek user approval before modifying the code.
