# Generate Test Plan

1. **Risk & Gap Analysis**: Evaluate the target code to identify all potential failure points, integration touchpoints, and test coverage gaps.
2. **Define Scenarios**: Outline an exhaustive set of test scenarios, covering happy paths, boundary conditions, edge cases, negative/error-handling paths, and integration points to ensure complete coverage.
3. **Document Strategy**: Record the identified scenarios and planned testing approach in a plan artifact to align on the validation strategy.
4. **Approval**: Present the plan to the user for feedback and explicitly stop to wait for approval before implementing any tests.
