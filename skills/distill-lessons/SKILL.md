# Distill Lessons

Distilling too often bloats the guidelines files, and therefore the context window of every future session.

1. **Qualify the Lesson**: Review the conversation and recent work for what it taught. A lesson qualifies only if it would have changed how this work was done and it generalizes beyond this task.
2. **Locate the Target**: Detect where the project's durable guidance already lives, preferring its agent instructions file, and propose one target rather than assuming a filename.
3. **Draft the Edit**: Write the lesson as a concise, generic principle folded into the existing section that covers the topic, not appended as a new one. Prune restated or stale guidance when the file has grown.
4. **Stop for Approval**: Present the proposed target and the exact edit, then wait for approval before writing to any file.
