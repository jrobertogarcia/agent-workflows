# Distill Lessons

1. **Reflection**: Analyze the current conversation and recent work to identify high-leverage patterns, friction points, or best practices discovered.
2. **Codification**: Update relevant project documentation (such as developer guides, repository instructions, or coding standards) with concise, generic principles to improve the quality and alignment of future work.
