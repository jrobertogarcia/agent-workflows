# Web Research

1. **Conduct Web Search**: Perform extensive and targeted web searches to capture current technical standards, authoritative documentation, and engineering best practices.
2. **Objective Analysis**: Rigorously evaluate findings from primary sources and a clean perspective, focusing on modern architecture, security, performance, and real-world trade-offs.
3. **Structured Reporting**: Summarize the findings cleanly and logically to present a robust, well-organized technical analysis.
4. **Suggested Next Steps**: Conclude with a clear set of actionable recommendations on how the findings can be practically applied.
5. **No Code / No Plan**: Do not modify code or draft implementation plans during the research phase. Create a file only when requested.
